# Roadster

A Big Ambitions mod: a Roadster with a thruster launch (0-60 mph in 0.81 s) and a thruster hop.

Version 0.0.1, a phase 0 spike with the Roadster model. Not tested in game yet. Lights glow all the time and the dealer colour doesn't repaint the body yet.

## Controls

- **Launch:** full throttle from a standstill.
- **Hop:** J while driving the Roadster.

## Install

Copy the `Roadster` folder into `ModsLocal` with the game closed. The mod changes every save it loads; removing it later loses any Roadster in those saves.
